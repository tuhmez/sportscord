# Sportscord

## About

Project for utilizing Sports Stats Web Service in Discord for baseball stats, standings, and subscribing to live games.

## Python Usage

Had used Anaconda in the past. Also supports standard Python PiP packages.

```bash
# if no .venv; make sure to use python 3.12
python3.12 -m venv .venv

# start venv; environment should be prefixed in terminal
. venv/Scripts/activate

# install packages
pip install -r requirements.txt

# turn off venv
. venv/Scripts/deactivate
```
